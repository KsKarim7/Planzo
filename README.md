# Planzo Overview


## 🟥 **Sprint 1 — Authentication & User Management**

### User Registration

The system allows new users to create accounts by providing required credentials, enabling secure access to the platform and participation in projects and collaboration features.

### User Login

The system authenticates registered users through secure login, granting access to personalized dashboards, projects, and protected functionalities within the application.

### Secure Authentication

The system uses token-based authentication to protect user sessions, ensuring only authorized users can access sensitive routes and perform restricted operations.

### User Profile Management

The system provides user profile viewing and updating features, allowing users to manage personal information and maintain identifiable presence across projects.

### User Search

The system enables searching for other users, supporting collaboration by making it easier to locate and add members to projects or teams.

---

## 🟨 **Sprint 2 — Project & Team Management**

### Project Creation

The system allows users to create projects, providing structured workspaces where tasks, teams, and collaboration activities can be organized efficiently.

### View User Projects

The system displays all projects associated with a user, allowing quick navigation between active and past projects.

### Update Project

The system supports updating project details, ensuring project information remains accurate as goals or requirements change.

### Delete Project

The system allows authorized users to delete projects, helping maintain an organized workspace by removing obsolete projects.

### Project Member Management

The system enables adding and removing members within a project, supporting controlled collaboration and access management.

### Role Management

The system assigns roles such as Owner, Manager, and Contributor, controlling permissions and responsibilities within each project.

### Team Assignment

The system allows teams to be added or removed from projects, enabling group-based collaboration without individual member management.

---

## 🟦 **Sprint 3 — Task Management & Kanban Board**

### Task Creation

The system allows users to create tasks within projects, converting project requirements into actionable and trackable work items.

### View User Tasks

The system provides a personalized task list, allowing users to track tasks assigned specifically to them across projects.

### View Project Tasks

The system displays all tasks within a project, helping users understand overall workload distribution and progress.

### Update Task

The system allows task updates, including status and details, ensuring tasks reflect current progress and responsibilities.

### Delete Task

The system supports task deletion to remove irrelevant or completed tasks, maintaining clarity within the project workflow.

### Kanban Board Visualization

The system visually organizes tasks into workflow columns, offering an intuitive overview of task progress and project status.

### Move Tasks Across Columns

The system allows tasks to be moved between Kanban stages, visually reflecting real-time progress updates.

---

## 🟩 **Sprint 4 — Activity Logs & Reports**

### Activity Log Tracking

The system records important user actions within projects, creating a transparent timeline of events for monitoring and accountability.

### Activity Visibility

The system allows users to view project activity history, ensuring awareness of changes even when users are not actively participating.

### Report Generation

The system generates project reports summarizing activities and progress, providing structured insights for evaluation and decision-making.

### Transparency & Accountability

The system promotes accountability by maintaining logs of user actions, improving trust and traceability within collaborative environments.

### Management Overview

The system provides managers and owners with high-level insights through logs and reports, supporting effective project monitoring and oversight.
